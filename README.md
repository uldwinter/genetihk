# CiteReady

White-label AI Search Readiness Auditor для SEO-агентств, веб-студий, маркетологов и владельцев сайтов.

## Возможности

- локальный анализ HTML или текста страницы;
- readiness score по пяти категориям: доступность, структура, ответность, доверие и свежесть;
- проверка title, description, canonical, robots, lang, H1, заголовков, alt, Schema.org, авторства, дат и источников;
- приоритетный список проблем и пошаговый план исправлений;
- генерация FAQPage JSON-LD, `llms.txt`, answer blocks и content brief;
- сохранение до 30 аудитов в браузере;
- экспорт JSON, CSV и PDF;
- white-label брендирование отчётов;
- адаптивный интерфейс и PWA-метаданные.

## Архитектура

Zero-dependency статическое веб-приложение. Анализ выполняется в браузере: HTML клиентов не отправляется на внешний сервер, база данных и платные API не требуются.

## Запуск

Откройте `index.html` локально или разместите ветку на Vercel.

## Ограничения

CiteReady — диагностический инструмент. Он не гарантирует попадание страницы в AI Overviews, AI Mode или ответы сторонних систем. Для автоматического аудита по URL можно добавить серверный crawler отдельным коммерческим модулем.
