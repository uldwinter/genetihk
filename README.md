# ReturnFlow

White-label портал возвратов и обменов для интернет-магазинов.

## Возможности
- self-service заявка;
- обмен, store credit и refund;
- операционная панель;
- аналитика причин;
- правила и брендирование;
- CSV export;
- адаптивная версия;
- демо без сервера и зависимостей.

## Монетизация
Брендированная установка 25–70 тыс. ₽, интеграция с CMS 30–120 тыс. ₽, сопровождение 5–20 тыс. ₽/мес.
